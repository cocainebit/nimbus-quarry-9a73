# Imported Astro designs

These are upstream designs built from pinned original repositories, not generated lookalikes. Moon is featured for its cinematic composition. AstroWind and Astroship are conventional contemporary business options. AstroPaper and Astro Sphere are secondary developer/editorial options; they are not presented as matching the bespoke agency references.

## Reproduction and adaptation

Original sources, package manifests, lockfiles and licenses are retained in `vendor/templates/<id>/` and in the downloadable `upstream-source.zip` included with each static export. Build with the instructions in `PLOTFORM-BUILD.md`. Dependencies were installed with lifecycle scripts disabled before executing the reviewed framework build command.

Static changes: asset and navigation attributes are made relative; framework scripts preserve their original JavaScript syntax; remote display images are vendored with source URL maps; fonts retain their licenses; demo forms do not submit to upstream services. Internal URLs generated by search resolve to the exported `index.html` files. AstroWind’s external Netlify/Decap CMS demo is omitted from the static distribution, while its source is retained. Unavailable upstream tutorial illustrations use explicit unavailable-image placeholders (nine in AstroPaper and one in Astroship), rather than broken remote requests.

## Verification

`tests/browser/modern-astro-templates.spec.ts` checks all five original home pages at desktop and phone sizes for missing assets, external requests, runtime errors and horizontal overflow. It verifies a real editable Moon headline in the ZIP export and the presence of its original framework source. It also searches actual bundled AstroPaper article data and follows a result into the exported article. Desktop and mobile catalogue images are screenshots of the actual local builds.

What is in here, and whose it is

Full provenance, per asset, is in SOURCE.json next to these pages.

  • PaperCSS

    The foundation this edition is adapted from: a sketchbook component layer whose irregular border radii and offset shadows are the reason a plain rectangle can look drawn. Its ideas were rewritten rather than its stylesheet vendored, partly so the edition could drop its remote Google Fonts import.

    ISC Licence, copyright 2017 to 2018 Rhyne Vlaservich

    licenses/papercss-ISC.txt https://github.com/papercss/papercss

  • Rough.js

    Draws every hand drawn graphic here: the rules, the frames, the pinned note, the tool sketches, the floor plan and the chart. It runs once at build time in tools/make-art.mjs and writes static SVG files, so nothing is redrawn in the browser and no stroke ever moves.

    MIT Licence, copyright 2019 Preet Shihn

    licenses/roughjs-MIT.txt https://github.com/rough-stuff/rough

  • Open Peeps

    Every person on this site. A hand drawn illustration library by Pablo Stanley, which openpeeps.com places in the public domain under CC0, so no attribution is required. It is credited here anyway. It is the reason this edition can show a room full of people without one photograph.

    CC0 1.0, public domain, no attribution required

    licenses/open-peeps-CC0.txt https://www.openpeeps.com

  • react-peeps

    The machine readable copy of the Open Peeps artwork, by Emre Cakir. tools/make-people.mjs renders its components once at build time into the static SVG figures in the assets folder. No React reaches the browser.

    MIT Licence, copyright 2020 to present Emre Cakir

    licenses/react-peeps-MIT.txt https://github.com/CeamKrier/react-peeps

  • Bricolage Grotesque

    The one typeface on the site, by Atelier Triay, bundled as a local variable woff2 with the weight axis. Nothing is requested from a font service.

    SIL Open Font License 1.1, copyright 2022 the Bricolage Grotesque Project Authors

    licenses/bricolage-grotesque-OFL.txt https://github.com/ateliertriay/bricolage

On the pictures

There is no photography on this site, and no generated images. Every graphic is an SVG file written by a script in tools/: the drawn furniture by Rough.js, the people by Open Peeps. Nothing was taken from any reference site.

Both scripts run once, at build time, and write files. Rough.js re-rolls its strokes on every render, so drawing in the browser would make the page jitter and would break the source editor's hold on whatever leaf you had selected. Every call passes an explicit seed, so running the scripts again writes the same bytes.

Nothing on any page requests anything from another host. No scripts, no fonts, no trackers, no maps and no form services.

On the content

Fettle is an illustrative workshop written for this template. The classes, tutors, timetable, bench numbers, address and fees are examples rather than a real organisation, and nothing here can be booked. Replace all of it before publishing.

Write to the bench about a place, an induction or getting in through the yard.

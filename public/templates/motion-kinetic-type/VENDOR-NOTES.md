# Plotform adaptation

Original Codrops Kinetic Type Page Transition, a 2021 motion foundation, not a full business website. Source commit is pinned in SOURCE.json. MIT source retained. Upstream credits photographs to Unsplash; they remain demo photography.

Changes: replaced Adobe Typekit fonts with locally bundled OFL Inter and Playfair Display; added keyboard activation and named back control; reduced-motion preference greatly accelerates animation. Original composition and GSAP typography transition retained.

Build: npm install; npm run build. No accounts, data backend, commerce or contact submission are supplied by this design foundation.

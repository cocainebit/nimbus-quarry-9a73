# Commonplace — a Plotform studio adaptation

This is an authored adaptation, not an unmodified upstream template and not an additional independently sourced repository.

Foundation: Launch UI, https://github.com/launch-ui/launch-ui, pinned revision b0d4d5bce91d13523450416ce1797109076b2787, MIT, copyright 2024 Mikolaj Dobrucki.

Reused material: original light/dark dashboard PNGs and CSS foundation tokens for neutral surfaces, radius and component shadows. Original source and license are retained. The editorial composition, typography pairing, copy, responsive layout, audience tabs, FAQ, pricing display and local workspace preview are Plotform adaptation work.

Typography: Inter and Newsreader, self-hosted under their SIL Open Font Licenses. Their license texts are in licenses/.

The design direction takes cues from the editorial restraint and two-audience presentation requested by the user. No Jack & Jill, Little Plains or Rome Michal source code, logos, copy or imagery is included.

The product screenshots and sample projects are illustrative. The workspace modal is a local demonstration; it does not provision accounts, save user data, submit requests or charge for subscriptions. Billing controls only switch the example display. Connect a real backend before offering the illustrated service.

All files needed for this static site are local. Open index.html through a static server. No build step or external CDN is required. The source archive includes the complete adaptation and the original Launch UI framework source archive.
